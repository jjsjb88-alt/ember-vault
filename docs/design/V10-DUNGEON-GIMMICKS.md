# V10 — 능력 풀에 따라 달라지는 심층 원정

2026-11-07 KST. 목표는 심층의 「용의 기억」을 회수해 입구에서 탈출하는 것이다. 이 문서는 V9.9의 네 구역·세 정비소에 추가한 통로와 기믹을 설명한다. 20개 방을 유지하면서 경로의 조건과 귀환 연결을 바꿨다.

## 클랭크에서 가져올 만한 것

비교 대상은 Clank! A Deck-Building Adventure 기본판의 알려진 규칙이다. [공식 출판사 페이지](https://www.direwolfdigital.com/clank/)와 룰북 도메인은 이 환경의 프록시가403으로 차단해 이번에 원문을 다시 대조하지 못했다. 다음은 원문 인용이나 최신 판본 검증 결과가 아니다. 세부 수치와 추가 기믹은 Ember Vault 전용 설계로 구분한다.

| 발상 | 클랭크의 알려진 구조 | V10에 구현한 선택 |
| --- | --- | --- |
| 수정 동굴 | 일반 이동으로 들어간 턴에는 더 이동할 수 없어 턴 계획이 필요 | 공명 수정고에 들어오면 그 턴의 추가 이동 금지. 상자·숨죽이기 등은 가능. 금화와 영구 열쇠를 얻지만 쉬는 턴의 추적·숨결을 고려 |
| 몬스터 통로 | 통로의 몬스터를 공격 자원으로 처리하거나 피해를 감수 | 갈림길↔중층 정비소는 이동 +1, 공격1 소비. 부족하면 피해1이며 방어 적용. 추가 소리1. 공격을 준비한 짧은 길과 수정고의 긴 길 비교 |
| 추가 발자국 비용 | 통로마다 필요한 이동 자원이 달라짐 | 검문 통로의 추가 이동 비용을 실제 자원 지출·사전 예고·귀환 계산에 함께 적용 |
| 시장의 열쇠 | 마스터 키를 구입해 잠긴 통로 이용 | 수정고에서 무료 획득하거나 준비한 정비소에서 금화5 구매. 영구 보유. 수로↔하층 정비소 지름길 개방. 가격과 상자 획득 경로는 우리 설계 |

일방 낙하와 수문 사다리, 압력 바닥, 두 방식의 봉인, 소리·추적까지 연결되는 비밀길은 **이번 게임에 맞춰 추가한 공간 규칙**이다. 원작 기본판의 소음 큐브 주머니와 다인 경쟁 종료 절차를 이번 변경에서 이식한 것은 아니다. 현재의 경계·방별 메아리·숨결 경로·14턴 귀환 제한을 유지한다.

## 층별 결정

| 구역 | 가기 전 준비 | 지도에서 결정할 것 |
| --- | --- | --- |
| 상층 | 보급함과 순찰길, 첫 영입·정리·보급 | 중층 검문에 공격을 쓸지, 수정고로 돌아 열쇠를 얻을지 |
| 중층 | 검문 통로 또는 수정고→수비실 | 이동력과 공격을 검문에 소비할지, 수정의 정지 턴을 감수하고 전투·상자 보상을 챙길지 |
| 하층 | 열쇠, 이동 방식, 수문용 기술1 | 파수병→압력 바닥→열쇠 지름길 / 모닥불·금고 우회 / 일방 낙하→수문→정비소. 낙하 뒤 되돌아갈 수문을 열 것인지 |
| 심층 | 전투 능력 또는 이번 턴의 기술2+은신3 | 봉인병 격파 / 공명제단으로 봉인과 비밀길 개방. 두 경로 모두 마지막 수호룡을 상대. 귀환 승강기 기술3·기본 소리8도 별도 준비 |

- 압력 바닥은 걷기·질주 진입에 추가 소리2. 살금살금 진입에는 추가 소리가 없다. 최종 소리에는 은신과 첫 소음이 적용된다.
- 열쇠 문은 처음 통과할 때 열린다. 열쇠를 가지고 있기만 해서는 소리가 통하지 않는다. 열린 뒤에는 소리·적·숨결도 양방향으로 지난다.
- 낙하구는 울림의 문턱→침수 서가로만 이동한다. 소리는 처음부터 양방향으로 전해진다. 수문 조작실에서 기술1·기본 소리5로 귀환 사다리를 열면 왕복한다. 열지 않아도 다른 우회로로 돌아갈 수 있다.
- 봉인병은 자리를 지킨다. 격파하면 기억실의 문을 연다. 다른 적은 기존처럼 소리를 조사한다.
- 공명제단은 기술2와 은신3을 정확히 소비한다. 소리를 내지 않고 첫 소음도 소비하지 않는다. 기억실로 실제 왕복 비밀길이 생긴다. 제단의 일회 휴식은 봉인 해제와 별도다.
- 비밀길과 승강기는 실제 그래프에 추가된다. 적의 이동과 소리, 숨결, 지도, 조작, 귀환 경로가 같은 연결을 사용한다. 닫힌 문은 그래프에 표시되지만 실제 전파와 이동을 막는다.

## 설명과 조작

녹스가 다음 층의 장소와 위험을 먼저 이야기하고, 수치가 있는 준비 안내가 능력 선택 위에 표시된다. 「메뉴 → 통로와 기믹」 또는 펼친 지도의 「통로·기믹 보기」에서 현재 연결된 경로마다 이동력·예상 최종 소리·공격/방어 소비·피해·잠금 이유를 크게 읽는다. 걷기·살금살금·질주를 비교하는 동안 저장·턴·난수는 변하지 않는다. 명시적으로 경로 이동을 누르면 그 방식으로 실제 이동한다.

작은 출구 표시는 검문·수정·열쇠·낙하·봉인의 종류를 알리고, 자세한 비용은 위 화면에서 비교한다. 지도는 잠금과 특수길에 점선을 쓰고 열쇠·봉인·방향을 표시한다. 열린 비밀길은 다른 방에 붙어 보이지 않도록 곡선으로 그리며, 별도 출구와 클릭 영역을 갖는다.

## 저장과 범위

새 `staged` 원정에만 `gimmicksVersion:1`을 붙인다. V9.9의 네 구역 원정, 이전20방/16방 원정, 회상 튜토리얼은 저장한 규칙을 유지한다. 새 탐험 확인에서 시작하기 전에는 기존 진행과 최고 기록을 바꾸지 않는다. `gimmicks:false`는 과거 규칙 재현 검증용이다.

새 지도는 고정 배치이며 절차 생성이나 추가 던전은 이번 범위에 포함되지 않는다. 원정 구조가 성립하는 검증과 사람이 처음 익힐 때의 난이도 평가는 구분한다. [실행 검증 기록](../production/V10-GIMMICKS.md)을 함께 확인한다.
