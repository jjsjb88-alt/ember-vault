# V7 검수 — 중복 조작 통합

검수일: 2026-10-29 KST. 관리형 미리보기의 실제 브라우저에서 입력했습니다. 테스트용 화면 크기 선택기를 통해 게임 iframe의 CSS 뷰포트를 변경했으며, 실제 휴대폰 장비 검수는 아닙니다.

## 변경과 관찰 결과

- 상시 오른쪽 패널과 그 안의 이동 목록, 중복 상호작용 버튼을 제거했습니다. 일반 장면에서는 방 버튼과 적·물체 버튼만 해당 행동을 수행합니다.
- 미니맵 하나가 소리 지도의 진입점입니다. 지도가 열리면 미니맵·장면 이동 버튼이 동시에 숨고, 지도에서 연결된 방을 클릭하면 실제로 이동 후 닫힙니다. 창고 → 떠돌이의 쉼터로 이 동작을 확인했습니다.
- 지도는 현재 발생 소리와 실제 청취한 적을 표시합니다. 반응한 적이 여러 명일 때 한 개의 다음 버튼으로 넘깁니다. 지도 노드와 글자는 CSS 화면 크기에 맞춰 그립니다.
- 이동 방식은 선택창에서 바꾸고 즉시 닫힙니다. 키보드로 열기 → 아래 방향키 → Enter를 입력하면 걷기에서 은밀로 바뀌고, 방 버튼의 비용·소음이 갱신됩니다. 열 때 현재 방식으로 포커스가 이동합니다.
- 교역 창에서 잰걸음을 기술 2로 구매해 기술 3 → 1, 해당 상품 교체를 확인했습니다. 네 상품은 가로 화면 한 줄, 세로 화면 네 줄로 표시됩니다. 기술 부족 상품과 금화 부족 교체는 비활성입니다.
- 숨죽이기로 이동 3 → 2, 경계 3 → 1, 은신 +2를 확인했습니다. 추출 영역을 누르면 이번 추출 상세가 열립니다.
- 탐험 메뉴의 여덟 항목, 교역 창, 지도·탐험 화면을 작은 가로 화면에서 검사했습니다. 별도 스크롤은 필요하지 않았습니다.

## 튜토리얼 회귀 검수

새 화면의 조작만으로 8단계 전체를 진행했습니다. 입구 → 창고 → 상자 → 미니맵 → 지도를 닫고 유인 → 질주 선택 → 파수병 방 → 풀 뽑기 → 파수병 공격 → 방패 밀치기 보상 선택을 확인했습니다.

질주 후 경계 10, 턴 종료 시 적 반격 1과 용의 공격 3으로 체력 22 → 18이 됐습니다. 새 추출의 공격 2로 파수병 체력 2를 모두 소모하고 실제 보상을 선택했습니다. 완료 후 원래 탐험의 입구·체력 22·금화 0·공격 2·이동 5·기술 3·경계 0이 복원됐습니다. 소음·용 연출은 계속 작동하며 규칙과 추출 RNG는 수정하지 않았습니다.

## 자동 검사와 범위

`npm run check`, `npm test`의 기존 30개 테스트, `git diff --check`를 실행합니다. 튜토리얼 완주·추출 합계·RNG·피해 순서·소리 전파·180개 시드 탐험 검증을 포함합니다. 관찰한 브라우저 오류 로그는 확장 프로그램의 metadata 전송 오류였으며, 해당 UI 흐름에서 게임 JavaScript 오류는 관찰하지 않았습니다.

이번 브라우저 검수는 UI 재구성과 튜토리얼 회귀에 집중했습니다. 일반 탐험 전체 탈출은 V6의 4턴·71점 완주 기록을 참고하며, 이를 V7에서 새로 완주한 결과로 표시하지 않습니다. 실제 모바일 장비의 프레임률·오디오·터치 정확도와 모든 시드의 밸런스를 보장하는 검사는 아닙니다.
