# 8방향 모션 제작 계획

상태: **조사 완료, 런타임용 아틀라스 미완성**. 이 저장소에는 완성된 8방향 모션을 포함하지 않는다.

참고 저장소: https://github.com/aldegad/sprite-gen

이전 조사에서 확인한 기준: v3.3.0, commit `76c507baea0ab450c09ed9b621417e888aba9afb`. 외부 소스나 라이선스를 이 프로젝트 소유 코드로 간주하지 않는다. 실제 도입 시 해당 리비전과 Apache-2.0 고지를 확인한다.

## 입력과 출력

1. 확정 목업의 시점에 맞는 전신 기준 이미지를 직업마다 만든다.
2. 여덟 방향별 단일 포즈를 확정한다. 오른손·왼손과 무기/등불/방패 위치를 검수한다.
3. 같은 방향 기준 포즈를 참조해 걷기 8프레임과 공격 6프레임을 동작별로 독립 생성한다. 직업당 최소 112개 동작 프레임이며 대기는 별도다.
4. 배경 투명도, 프레임 추출, 발 접지점과 크기 정렬, 아틀라스 합성을 수행한다.
5. `manifest.json.frame_layout.rows`의 절대 사각형과 `animation.rows`의 FPS·duration·loop 정보를 런타임에서 소비한다. 픽셀을 보고 격자를 추측하지 않는다.
6. 기준 프레임은 192×192, 접지점은 하단 여백을 둔 공통 좌표를 출발점으로 검증한다. 무기나 망토가 잘리면 캔버스 또는 배치를 조정한다.

## 검수

- 걷기의 양발 접지와 상반신 반대 흔들림, 루프 시작/끝 연결.
- 공격의 준비·타격·후속 동작·복귀, 타격 시점과 실제 게임 효과의 동기화.
- 방향별 얼굴·의상·무기 동일성, 크기 변화·접지 미끄러짐·관절 왜곡 여부.
- 모든 방향을 실제 속도로 재생하여 확인. 정지 시트만으로 합격 처리하지 않는다.
- 이동 속도는 걷기·은밀·질주 모드에 맞추되 자원 소비와 방 연결 규칙을 바꾸지 않는다.
- 모바일 메모리 사용량을 고려해 선택한 직업부터 로드한다. reduced-motion 설정을 존중한다.

## 기존 시도의 한계

방향별 기준 포즈와 오프라인 추출 방식 검토가 시작됐지만 완성된 요청 파일·아틀라스·검수 결과가 현재 체크아웃에는 남아 있지 않다. 이를 구현 완료나 합격한 모션으로 기록하지 않는다. 재개 시 확정된 새 목업 시점에 맞춰 제작한다.

사용 가능한 이미지 생성 경로에 맞춰 생성 모드와 프롬프트를 기록한다. 내장 이미지 생성으로 입력을 만든 경우 외부 CLI 또는 영상 생성기가 생성했다고 주장하지 않는다.
