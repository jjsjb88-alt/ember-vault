테두리의 작은 등급 장식은 능력 수치와 분리한다. 하단 도크는 작은 아이콘을 누르는 요약이며, 긴 설명은 큰 목록에서 읽는다. 휴대폰에서 hover나 마우스 전용 툴팁을 요구하지 않는다.

`ability-guide.js`가 기존 `CARDS`의 실제 효과에서 이름·숫자를 읽고, 게임과 도감이 이를 공유한다. 대사·원화·효과 수치·영입 비용은 그대로다. 사전은 출발한 메달 페이지·교역·보상으로 돌아온다. 보상 대기 중 닫기와 Escape도 원래 선택지를 복원한다.

## 뜻을 구체적으로 설명한 키워드

- **은신:** 내 소음을 줄이는 남은 양이다. 소리를 줄인 만큼만 소모하고 남은 양은 같은 턴에 계속 쓴다. 은신3에서 소리2를 내면 무음이 되고 은신1이 남는다. 돌멩이 유인에는 적용되지 않으며, 이미 남긴 메아리는 지우지 않는다. 기존 안내의 “다음 개인 행동에만 적용”이라는 부정확한 표현도 고쳤다.
- **첫 소음:** 다음 내 소리 행동에 한 번 추가된다. 해당 행동 뒤 소모되며 은신으로 줄일 수 있다. 유인에는 소모되지 않는다. 기본 소리2·첫 소음1·은신2이면 실제 소리는1이다.
- **추가 추출:** 이번 추출에서 실제 뽑을 수 있는 메달을 더 공개하고 자동 합산한다. 추가 턴이나 다시 누르는 사용 버튼이 아니다. 이번 공개 중인 메달은 다시 순환하지 않는다.
- 공격·이동·기술·방어·회복·금화도 사용 시점과 유지 여부, 숫자 예시를 사전에 적었다. 등급이 능력 보너스를 별도로 더하지 않는다는 점도 명시했다.

## 클랭크 질문과 현재 게임의 유물 효과

비교 대상은 **Clank! A Deck-Building Adventure 기본판**이다. [공식 출판사 페이지](https://www.direwolfdigital.com/clank/)와 출판사 상품 페이지에 접속을 시도했으나 환경 프록시403으로 차단되어 룰북 원문을 이번에 새로 대조하지 못했다. 아래 원작 열은 알려진 기본판 규칙에 대한 정리이며 원문 재검증 완료로 표시하지 않는다.

| 구분 | 클랭크 기본판의 알려진 규칙 | 현재 Ember Vault |
|---|---|---|
| 유물을 얻을 때 | 용의 분노가 상승해 이후 공격 위험이 커짐 | 봉인 소리8, 메아리 유지 단계 상승, 최초 귀환 제한14턴 시작 |
| 유물 소지 후 매턴 | 소지자에게 일률적인 고정 피해를 주는 규칙은 아님 | 턴 종료마다 귀환 제한1 감소. 매턴 고정 체력 손실은 없음 |
| 종료 압박 | 누군가 먼저 탈출하거나 쓰러진 뒤 카운트다운 진행 | 유물을 들고 있으면 전체 턴 수가3의 배수일 때도 숨결 발동 조건이 됨 |
| 실제 피해 | 누적한 소음과 공격 시 주머니 추출에 따라 결정 | 메아리의 경로·현재 위치·방어에 따라 결정. 주기 공격이라도 안전한 방에서는 피해가 없을 수 있음 |

Ember Vault의 주기 숨결은 유물 획득 후 “세 턴이 지났다”가 아니라 **현재 턴3·6·9…의 종료**를 기준으로 한다. 경계8 이상도 별도 발동 조건이다. 유물을 더 높은 것으로 바꿔도 남은 귀환 시간은 초기화되지 않는다. 메아리 유지 단계는 최대3이며, 희미해지는 간격은1→2→3→4턴으로 늘어난다. 사전은 현재 저장의 실제 간격과 남은 귀환 시간을 표시한다.

원작의 유물 규칙을 추측해 새 체력 디버프를 추가하지 않았다. 이번 변경은 기존 게임의 지속 압박을 읽을 수 있게 하는 표시 개선이며 엔진·RNG·저장 형식은 변경하지 않았다.
