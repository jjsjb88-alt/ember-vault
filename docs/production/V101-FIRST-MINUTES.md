## 리뷰와 실제 코드 대조

기존 상세 연습은23단계가 아니라18단계였다. 정비소 밖 교역도 이미 비활성이었고 버튼 이름은「정비소」였다. 그러나 첫 접속이 긴 프롤로그와 별도 회상으로 이어지고, 작은 잠금 안내만으로는 조건을 알아보기 어려운 문제는 유효했다. 리뷰의 단검2+불씨3 경험과4/6통로 귀환 비교는 별도 회상의 사례다. 본게임의 실제 주머니에 같은 다음 추출을 보장한다고 해석하지 않았다.

## 흐름과 저장

짧은 안내는 행동을 차단하는 단계표가 아니다. 상자 대신 첫 적을 고르거나, 능력 대신 보급·정리를 골라도 정상 규칙으로 진행한다. 필요할 때 작은 깜부기 안내를 펼치거나 접을 수 있다. 영입한 능력이 실제 다시 나오고 관련 자원을 사용한 뒤 다음 구역으로 나아가면 안내를 마친다. 늦어도 하층에서는 자동으로 접는다. 자원과 경로는 플레이어가 결정한다.

처음 공개하는 목록은 실제 메달5개와 직업의 기본 힘을 함께 보여 준다. 가로 화면에서는 목록을 스크롤하고 합계와 출발 버튼을 읽을 수 있다. 기존의 단계별 추출 연출은 유지하며 짧은 안내의 첫 결과만 즉시 확인한다. 모든 내용은 이미 확정된 추출을 읽어서 그린다.

첫 안내 상태는 원정에 선택적 `firstRun` 메타데이터로 저장한다. 진행 중 새로고침해도 영입·턴·주머니를 복제하지 않는다. 기존 저장에 메타데이터를 강제로 붙이지 않는다. 첫 접속의「안내 없이 탐험」도 가능하다. 이전 상세 회상의 별도 저장·재개·취소·결산은 유지한다.

기존 이용자는 상층·중층에서「메뉴 → 상층 짧은 안내」를 열거나, 새 탐험에서「깜부기의 짧은 상층 안내와 함께」를 선택할 수 있다. 메뉴 안내는 현재 원정을 초기화하지 않는다. 새 탐험은 기존처럼 명시적으로 시작할 때 초기화한다.

## 검증

- `npm run check`: 런타임30개 모듈 구문 검사 통과.
- `npm test`: **131/131 통과**. 신규7개는 실제 API 결과와 안내를 관찰한 결과의 규칙·자원·난수 동등성,30개 시드의 영입 후 실제 추출, 자유 행동과 안내 종료, 실제 전후 수치, 잘못된 선택적 저장 거부, 귀환 예보의 절대 턴, 실제 탈출 문장의 조사 처리를 확인한다.
- 전투/은신 ×3직업 ×30시드의 기존 심층 경로 **180회 완주**를 재확인했다. 고정 지도를 아는 정책이며 사람의 난이도·승률 검증은 아니다.
- **360×640·390×844·740×320**의 새 브라우저 컨텍스트에서 첫 접속→실제 상자→정비 영입→새로고침→정상 후속 추출→실제 전투→중층 진입을 터치 조작했다. 게임 상태·localStorage·난수 주입은 사용하지 않았다. 첫 결과가 자동으로 닫히지 않는지, 사용 가능한 출구 중심을 안내가 덮지 않는지, 잠금 문구, 실제 재등장, 보상 창의 수치도 확인했다. 가로 화면의 마지막 메달까지 스크롤해도 저장이 바뀌지 않았다.
- 기존18단계 상세 회상을390×844에서 다시 완주했다. 교역·보상·도감의 읽기와 원정 보호도 통과했다.
-740×320 마법사 원정은 세 정비소·고요의 봉인·수호룡·유물 회수·입구 귀환까지 완주했다.
- 고전16방·기존20방·V9.9 원정의 저장 보호·새 탐험 취소·명시적 시작·최고 기록 보존을 별도 격리 fixture로 재확인했다. 일반 플레이 검증과 구분한다.

브라우저 검증은 로컬 Chromium의 모바일 화면과 터치 모사다. 실제 휴대폰 인증이나 사람 초심자 실험은 아니다. 스크립트는 일부 대사·연출을 건너뛴다. 기록한 소요 시간을「사람이3분 안에 배웠다」거나 이탈률이 개선됐다는 근거로 해석하지 않는다. 첫3분에 필요한 선택을 먼저 제공하는 구조를 구현하고, 그 구조의 작동을 확인한 것이다.
