# V5.1 방 클릭 이동 검수

2026-10-28. 실제 입력을 Sites 로컬 미리보기의 Chrome에서 검수했습니다.

- 던전의 망각의 창고 버튼 클릭: 입구 → 창고, 이동력 5 → 4.
- 미니맵의 입구 클릭: 창고 → 입구, 이동력 4 → 3.
- 이끼 낀 회랑 클릭: 이동력 3 → 2, 전투 중 다른 방 잠김과 입구 후퇴 표시.
- 잠긴 부서진 무기고 클릭: 이동하지 않고 전투·후퇴 안내 표시.
- 입구 후퇴 클릭: 이동력 2 → 1. 창고 이동 후 0이 되면 풀 뽑기 안내.
- 이동력 0에서 방 클릭: 상태를 바꾸지 않고 필요한 이동력과 풀 뽑기 안내.
- 유인 모드에서 쉼터 클릭: 현재 방 유지, 기술 3 → 2, 돌멩이 소리 5 발생.
- 펼친 지도에서 입구 클릭: 창고 → 입구, 이동력 4 → 3, 이동 탭과 던전 화면으로 자동 복귀.
- 740×320, 844×390, 932×430, 390×844에서 페이지 크기와 화면 크기 일치. HUD 초상화의 의도된 돌출 외에 검사 대상 요소 넘침 없음.
- 전투 정보와 방 버튼이 겹치는 문제를 수정하고, 세로 화면에서도 실제 렌더링으로 확인.

모든 런타임 JavaScript 구문 검사와 25개 테스트를 통과했습니다. 이동 판정은 버튼·지도·엔진이 같은 함수를 사용하며, 연결되지 않은 방, 이동력 부족, 전투 중 후퇴 제한, 보상 선택 대기 상태를 테스트합니다. 빠른 연속 클릭은 450ms 동안 추가 이동을 차단합니다.

실제 휴대폰 하드웨어의 터치 지연은 측정하지 않았습니다. QA용 iframe 페이지는 배포 폴더에서 제외합니다.
