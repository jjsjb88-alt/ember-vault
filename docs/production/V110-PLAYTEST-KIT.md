# 모바일 웹 · 10분 원정 사람 테스트

현재 사람 참가자: **0명**. 자동 탐험·브라우저 자동 조작은 참가자 수에 포함하지 않는다. 직접 연락하거나 모집 메시지를 발송하지 않았다.

## 진행 방법

1. PR을 병합·배포한 버전인지 먼저 확인하고 새 브라우저 기록으로 시작한다. 기종·OS·브라우저·버전을 기록한다. 새 원정만 V11 규칙을 사용한다.
2. 첫 원정은 설명을 대신 읽어 주지 않는다. 필요하면 게임의 깜부기 안내와 사전을 사용한다. 시작부터 결과까지 실제 경과 시간을 잰다. 중단한 경우 마지막 단계와 이유도 기록한다.
3. 소리는 직접 켜게 한다. 조용한 상태와 경계가 쌓인 상태에서 숫자를 가린 채 위험 변화의 시점을 물어본다. 소리 듣기 테스트는 볼륨과 기기 차이를 함께 기록한다.
4. 「메뉴 → 플레이 테스트 기록」에서 선택 동의를 받는다. 원정 행동 기록은 이 기기에만 저장되고 서버로 전송되지 않는다. 의견과 JSON은 참가자가 원할 때 직접 내보낸다. 동의를 끄면 행동 기록을 지운다.
5. 재도전 기록으로 첫 승리까지 원정 수, 10번째 원정의 새로운 발견, 해금 선택의 이해도를 확인한다. 첫 승리를 강제로 미루거나 가상의 응답을 추가하지 않는다.

## 수집 양식

익명 참가자 ID / 버전 / 기종·OS·브라우저 / 세로·가로 / 소리 사용 / 첫 판 시간 / 결과 / 중단 지점·이유 / 첫 승리 원정 수 / 경계 상승을 소리로 구별했는지 / 메달 순환을 이해했는지 / 다음 선택이 궁금했는지.

목표는 20명 이상이다. 실제 모바일 웹의 약10분 완주, 초심자 첫 승리5~10판, 소리만으로 위험 구별, 번역 자연스러움은 이 결과로 판단한다. 현재는 모두 **사람 검증 대기**다. 자동 기록에는 시간과 행동만 남으며 기기 정보나 연락처를 자동 수집하지 않는다.

## 출시 전 남은 확인

- iOS Safari와 Android Chrome 실기기의 설치·오프라인·저장 이전. 브라우저의 저장 공간 회수 및 음원 출력도 확인.
- 영·일 원어민 검수 및 남아 있는 한국어 문장 보완. 상세 회상과 동적 일지까지 확인.
- 승인된 기존 생성 아트의 제작 계정·도구별 상업 이용 조건. 신규 그림60장을 만들었다고 표시하지 않는다.
- 효과음 CC BY4.0 표기 유지, 원곡 출처와 CC0 기록 최종 확인. 외부 코드 MIT 고지 유지.
- 실제 공개 Pages 배포 확인. 로컬 성공을 공개 사이트의 배포 성공으로 표시하지 않는다.
