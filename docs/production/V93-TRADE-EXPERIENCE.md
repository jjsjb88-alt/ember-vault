# V9.3 · 기억장수 세라와의 교역

2026-11-06 Asia/Seoul. 교역을 세계 안의 인물과 만나는 장면으로 바꿨다. 새 캐릭터 원화는 이번 작업에서 이미지 생성 도구로 제작한 `dist/assets/sera-refuge-v93.png`이며, CSS로 화면별 구도와 인물 초상을 잡았다.

## 만남에서 사용까지

이끼 회랑 끝의 등불 아래, 기억장수 세라가 사람들의 남겨진 솜씨를 메달로 벼린다. 첫 교역은 깜부기·세라·도적의 다섯 줄 대화로 시작한다. 세라가 왜 여기 있는지, 수호자에게 갈 도적에게 왜 불씨 화살을 건네는지를 말한다. 「세라의 이야기」에서는 주인을 기다리는 기억 때문에 공방을 떠나지 못한다는 사연을 듣는다.

작업대에는 캐릭터 원화, 지금 상황에 맞는 인사, 각 메달의 사연과 실제 효과·비용이 함께 보인다. 기술이 부족하거나 현재 안내와 다른 물건은 이유와 함께 비활성화된다. 일반 탐험에서는 유물 보유·부상·높은 경계에 맞춰 세라의 말이 달라진다.

불씨 화살을 깨우면 메달을 주머니에 건네는 네 줄 대화가 이어진다. 도적이 바로 쓸 수 있느냐고 묻고, 세라는 다음에 주머니가 섞일 때 돌아온다고 답한다. 이어지는 실제 추출과 수호자 전투가 그 말을 행동으로 확인하게 한다. 일반 거래는 짧은 전달 대화 뒤 영수증이 있는 작업대로 돌아온다.

다른 방에서 여는 교역은 피난처의 세라와 이어진 **황동 기억함의 잔상**이다. 기존의 어디서든 거래할 수 있는 규칙과 인물의 장소가 연결된다. 비용·메달 효과·추출 규칙은 기존 엔진을 사용한다.

## 저장과 조작

첫 만남과 마지막 구매를 탐험의 `tradeStory`에 기록한다. 대화는 엔진 자원을 소비하지 않는다. 성공한 구매는 기존 엔진으로 처리하고, 대화 전에 구매 결과와 튜토리얼의 다음 단계를 저장한다. 전달 장면에서 새로고침해도 메달이나 비용을 다시 지급하지 않는다. 연습과 본게임은 기존의 분리된 저장 방식을 유지한다.

컷신은 계속·건너뛰기 버튼, 엔터, ESC를 지원하며 모션 축소를 따른다. 일반 컷신은 대화 자체에, 세라 장면은 계속 버튼에 처음 초점을 둔다. 장식 배경은 터치를 가로채지 않는다. 작업대는 작은 화면에서 세로로 스크롤해 물건을 고를 수 있다.

## 실제 확인

`npm run check` 런타임 21개 모듈, `npm test` 86개 통과. [브라우저 결과 JSON](V93-BROWSER-RESULTS.json)에 이번 실행만 기록했다.

- 360×640, 740×320, 1280×720에서 실제 클릭·터치로 첫 만남부터 튜토리얼 탈출·결산까지 세 번 완주.
- 첫 만남 다섯 줄을 실제로 진행하고 대화 중 자원·금화·RNG 불변 확인.
- 이야기 보기→작업대 복귀, 불씨 화살 구매→전달 컷신 도중 새로고침→같은 구매 결과와 다음 단계 복원 확인. 기술은 3 한 번만 감소, 메달과 구매 수는 한 번만 증가, 본게임 저장·최고점 보존.
- 390×844 일반 탐험에서 기억함 첫 만남·새로고침 후 재방문·실제 메달 구매·영수증 복귀·구매 후 새로고침 확인. 엔터는 한 줄만 진행하고 ESC는 작업대로 연결.
- 별도 새 탐험에서 390×844·740×320·1280×720의 같은 만남과 작업대를 실제로 열어 크기를 바꾸며 추가 검수. 화면 안의 대화·44px 이상 계속 버튼·가로 넘침 없음·가로 화면 건너뛰기 터치 확인. 최종 대표 화면은 아래 링크에 보존.

검수 중 가로 화면에서 장식 설명이 건너뛰기 터치를 가로채는 문제를 발견해 수정했고 해당 실제 완주를 다시 실행해 통과했다. 최종 구도에서는 얼굴이 잘리지 않도록 가로 화면의 이미지 위치도 보정했다.

재현 도구: [행동·저장 검수](tools/verify-v93-browser.py), [장면·작업대 레이아웃 검수](tools/verify-v93-layout.py).

```bash
npm run check
npm test
python3 -m http.server 8013 --bind 127.0.0.1 --directory .
# 별도 터미널. Python Playwright와 /usr/bin/chromium 필요
python3 docs/production/tools/verify-v93-browser.py compact-map --base-url http://127.0.0.1:8013
python3 docs/production/tools/verify-v93-layout.py
```

Chromium 화면·터치 에뮬레이션이며 실제 iPhone/Safari·Android 기기 검수는 아니다. 게임 상태나 RNG 주입은 사용하지 않았다. 공개 Pages 주소 직접 접속은 환경 프록시 제한으로 확인하지 못하므로 로컬 성공과 GitHub Actions의 배포 상태를 구분한다.
