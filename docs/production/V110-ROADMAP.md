# V11 · 모바일 웹 10분 원정

PR #20의 개발 범위를1단계 위험 조정에서6단계 전체로 확장했다. 사용자가 정한 플랫폼은 **모바일 웹**, 목표 플레이 시간은 **약10분**이다. 기존18~25턴/20~30분 계획은 사람의 실제 시간 목표와 분리한다. 새 탐험에는 `campaignVersion:1`, `worldVersion:1`, `riskVersion:1`을 기록하며, 이전 탐험은 원래 규칙대로 이어진다.

고정 시작 메달이 모든 주머니에 들어가는 것은 설계상 필연이다.80% 기준은 **새로 영입한 메달**에 적용하며 실제 구매·정비·적 보상을 모두 센다. 채택은 해당 축만 쓰는 순수 덱을 뜻하지 않는다.

## 브라우저와 출시 도구 검수

`npm run check`80개 모듈과Node 테스트169개가 통과했다. 모든60메달의 효과·설명 UI를 렌더링하는 회귀 검사를 포함한다. [브라우저 원자료](V110-browser-results.json)는 새 UI에서 만든 시드를 읽고 정상 버튼을 터치해 진행했다. 위치·턴·체력·자원·주머니·난수·소리 순번을 정책 엔진과 매 행동 대조했으며 저장·난수를 주입하지 않았다.

[출시 도구 원자료](V110-release-results.json): 큰 글씨·색 보조·진동/움직임 설정, 저장 내보내기/검토/복원, 전체 패키지의 모든 파일 캐시 확인, 연결을 끊은 뒤 루트 링크 재접속과 실제 턴 진행을 검사했다. 업데이트는 별도의 워커 버전fixture로 명시적 적용과 원정 저장 보존을 확인했다. 음악8개·효과13개는 실제 파일을 디코딩했고 구역/정비/결산 트랙, 사용자 조작 후 재생, 위험층gain과 음소거를 검사했다. 귀로 들은 품질·위험 인지의 증거로 사용하지 않는다.

이 로컬 서버의 첫 접속 응답 본문 합계는 **9,692,097바이트**였다. 초기 워커의 코어 저장 요청까지 포함하며 HTTP헤더·실제 모바일 망/CDN 전송은 별도다. 실제 배포·실기기 검수와 구분한다.

## 저장·배포·재현

`npm run build`가 `_site`에 런타임 배포본을 만든다. 원본 PNG는 소스에 보존하고 배포에서는 사용하지 않는 PNG를 제외한다. 주인공 보행은 같은 해상도의 고품질 WebP이며 배경도 WebP로 전환했다. 공격·유물 동작과 음악은 필요할 때 불러온다. 빌더는 표시가 없는 출력 디렉터리를 지우지 않는다.

서비스 워커는 루트 공개 링크를 포함해 처리하며 초기 코어와 전체 패키지를 구분한다. 변경 파일의 해시를 확인해 이전 HTTP 캐시가 새 버전을 가리는 것을 방지한다. 업데이트는 저장 후 명시적으로 적용한다. 전체 오프라인 저장을 누르면 음악·동작까지 캐시한다.

저장 파일은 현재 원정·불씨·설정·최고점·연습 기록의 허용된 키만 포함한다. 가져오기 전 크기/JSON/버전/내용을 검증하고 확인 화면을 표시하며 쓰기 실패 시 기존 값을 복구한다. 서버 전송은 없다.

```bash
npm run check
npm test
node docs/plan/tools/measure-risk.mjs /tmp/risk-results.json
node docs/plan/tools/measure-campaign.mjs /tmp/campaign-results.json
npm run build
python docs/plan/tools/verify-release-ui.py
# 저장소 루트에서 고정 경로로 제공:
python -m http.server 8093 --directory _site
# 다른 터미널에서:
python docs/plan/tools/verify-campaign-ui.py 800 --base-url http://127.0.0.1:8093
python docs/plan/tools/verify-campaign-ui.py 390 --language en --base-url http://127.0.0.1:8093
```

Python Playwright, Chromium, 음원 재제작에는 `gh`와ffmpeg가 필요하다. 음악·효과음의 출처·해시·편집 내역은 [음악](AUDIO-SOURCES.json), [효과음](SFX-SOURCES.json), 게임 안 제작·출처 페이지에 보존한다. 효과음 제작 스크립트는 `tools/build-v110-sfx.py`, 음악은 `tools/build-v110-music.py`(이 문서 기준 `docs/production` 아래 경로)이다.

자동·브라우저 결과를 사람20명으로 세지 않는다. [사람 테스트 양식과 출시 확인](V110-PLAYTEST-KIT.md)의 참가자는 현재0명이다. 실제10분 경험, 첫 승리까지의 학습, 실기기 출력, 원어민 번역과 기존 생성 아트의 상업 권리 확인까지 끝나야 출시 완료로 표시한다.
