# V6 검수 — 튜토리얼·소음 추출·용의 분노

검수일: 2026-10-28. 정적 런타임 `dist/`, 관리형 미리보기의 실제 브라우저 입력으로 확인했습니다. 테스트 편의를 위한 화면 크기 선택기는 배포 파일에서 제외합니다.

## 실제 클릭 검수

### 튜토리얼

1. 첫 방문 안내에서 효과음과 함께 실습을 시작합니다.
2. 추출 중 소음 봉인이 공개된 시점의 부분 합계만 표시합니다. 공격 2·이동 4·기술 1·방어 0, 뒤의 두 능력은 비공개였습니다. `다음 행동 소음 +1`을 안내하고 확인 버튼으로 다음 봉인에 진행합니다.
3. 첫 방 이동 → 상자 열기 → 소리 지도 → 돌멩이 유인 → 질주로 8단계 실습을 진행합니다.
4. 질주 후 경계 10에서 용의 눈이 드러납니다. 통로의 파동과 청취한 적 표시는 실제 규칙 결과를 사용합니다.
5. 턴 종료 시 적 피해 1 뒤 용의 공격 3을 받아 체력 21 → 18이 표시됩니다. 확인하면 새 풀을 뽑습니다.
6. 파수병을 직접 눌러 처치하고 실제 보상 능력을 선택하면 연습이 완료됩니다.
7. 연습을 나가면 원래 탐험의 입구 위치·체력 22·금화 0·공격 2·이동 5·기술 3·경계 0이 복구됐습니다.

### 일반 탐험 한 판

이전에 시작했던 중간 실행은 브라우저 정리로 이어지지 않아, 새 일반 탐험을 처음부터 다시 시작해 끝까지 확인했습니다. 게임 상태를 주입하거나 개발자 실행으로 행동하지 않았습니다.

- 입구 → 창고 → 제단 → 서고 → 달의 봉인실로 이동했습니다. 이동 버튼의 자원·소음 안내와 실제 소모가 맞았습니다.
- 수호자 체력 5를 세 차례 공격으로 처치했습니다. 공격마다 실제 소음 연출이 열리고, 턴 종료 시 남은 방어가 반격을 흡수했습니다.
- 돌멩이를 마지막 불씨 방으로 던졌고 이후 적의 위치 변화가 보였습니다.
- 처치 보상으로 `새벽의 기도`를 풀에 영입했습니다.
- `달의 눈물`을 회수하면 경계 10·귀환 14턴과 용의 분노 안내가 나타났습니다.
- 서고 → 제단 → 창고 → 입구로 돌아와 문을 직접 눌렀습니다.
- 결과: **승리, 4턴, 적 1명 처치, 방 5개 방문, 금화 3, 남은 체력 20, 점수 71**. 계산은 유물 18 + 금화 3 + 탐험 10 + 체력 20 + 탈출 20입니다.

## 자동 검사

- `npm run check`: 런타임 JavaScript 문법 검사.
- `npm test`: 30개 테스트. 기존 25개 회귀 검증과 새 실습 전체 진행, 적 반격 후 용의 피해 계산, 실제 소리 도달 경로, 추출 예고의 정보 경계, 상호작용 가능 조건을 포함합니다.
- `git diff --check`: 공백 오류 검사.
- 브라우저에서 확인한 오류 로그는 확장 프로그램의 metadata 전송 오류였습니다. 관찰한 실행 흐름에서 게임 JavaScript 오류는 보이지 않았습니다.

## 검증 범위

소음 추출은 다음 개인 행동의 소음 예고이며, 그 자체로 경계를 올리거나 적을 이동시키지 않습니다. 행동 후 소리 전파, 턴 끝 적 이동·용의 공격을 분리해 보여줍니다. 예측은 실행 상태의 사본에서 적 반격만 계산하며 추출 RNG를 소비하지 않습니다.

연습의 소음·용 연출은 설명을 읽을 때까지 대기합니다. 일반 탐험에서는 짧게 재생한 뒤 자동 진행하며 언제든 건너뛸 수 있습니다. 모션 감소 설정에서는 흔들림을 없애고 연출 시간을 줄입니다.

효과음은 사용자 입력 후 브라우저 Web Audio로 합성합니다. 버튼과 재생 코드 연결은 확인했지만 실제 휴대폰 스피커·블루투스 장비로 청취 평가한 것은 아닙니다. 이번 단일 실전 완주는 모든 시드·직업의 난이도 균형을 보장하지 않습니다.
