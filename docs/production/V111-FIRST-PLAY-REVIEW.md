# 숨결 수업 첫 플레이 관점 검수 (2026-11-18)

대상: PR #21, `tutorial/breath-lesson`의 ea53cad223e5534eca7a4cbd0e64a8063b70d29b.

## 수정한 사실 불일치

- 경계 5 **이상**부터 적에게 소리가 더 멀리 전달된다. 기존 문구는 ‘다섯을 넘으면’이었다. 4/5/7/8 경계 테스트 추가.
- 경계가 높다고 메아리 소멸이 느려지지는 않는다. 소멸 주기는 memory/heat/메아리 실타래에 따른다. ‘소리도 더디게’, ‘턴마다 옅어짐’의 부정확한 단정 제거.
- 숨결 경로 밖인 방에도 메아리가 있을 수 있다. 안전 예고와 대사를 ‘조용함’ 대신 ‘현재 경로 밖’으로 정정.
- 유물을 가진 3의 배수 턴에는 경계 8 미만이어도 숨결이 온다. 경계 감소가 모든 숨결을 취소하는 것처럼 읽히던 회피 안내를 정정.
- 영어·일본어도 같은 의미로 갱신. 규칙, 난이도, 피해량 변경 없음.

## 초심자 경험 판단

행동 직후 상황에 맞는 짧은 수업과 되돌아가기 선택은 설명을 미리 읽게 하는 방식보다 낫다. 다만 코드상 수업을 화면에 표시하기 전에 읽음으로 저장하므로, 건너뛰거나 새로고침한 사람에게는 다시 나오지 않는다. 의도적인 ‘기기마다 한 번’ 정책이므로 이번 수정에서 바꾸지 않았다.

픽셀 효과는 이미 `dist/vendor/pixelfx`와 `cutscene`, `pool-reveal`, `noise-moment` 등에 연결되어 있다. 외부 PXF 사이트에서 새로운 에셋을 복사하지 않았다. 효과 추가보다 ‘어느 방이 안전한가’의 정확한 표현을 우선했다.

- 수정 후 자동 테스트 175개, JS 구문 검사, release build 실행.
