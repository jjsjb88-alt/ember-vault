# V10.0 기믹·지도 검증 기록

2026-11-07 KST. 런타임 캐시 `20261107e`. [설계와 클랭크 비교](../design/V10-DUNGEON-GIMMICKS.md).

## 구현 범위

새 네 구역 원정에 수정 동굴·검문 통로·열쇠 지름길·압력 바닥·일방 낙하와 수문·전투/은신 봉인을 추가했다. 잠금·방향·개방은 실제 이동, 소리, 적 추적, 숨결과 귀환 경로 계산에 반영한다. 제단 비밀길은 실제 연결과 별도의 지도 곡선·출구·클릭 영역을 만든다.

녹스의 다음 층 대화, 정비 선택 위 준비 안내, 준비 완료 후 금화5 영구 열쇠 구매를 연결했다. 「통로와 기믹」은 이동 방식별 실제 비용·예상 소리·공격/방어 소비·피해·막힌 이유를 읽고 경로를 선택하는 화면이다. 화면 안의 방식 비교는 실제 상태를 바꾸지 않으며 이동 확인 때 적용한다.

이번 지도는 기존20개 방의 고정 배치에 통로 조건과 개방 연결을 추가한 것이다. 새 이미지 제작이나 절차 생성 던전을 완료했다는 뜻은 아니다. 클랭크 공식 도메인은 프록시403으로 원문을 새로 대조하지 못했으며, 알려진 규칙과 이 게임의 추가 설계를 설계 문서에서 분리했다.

## 실제 브라우저 조작

Python Playwright + 로컬 Chromium, 터치·모바일 뷰포트·동작 감소 설정. 일반 원정과 안내 화면 테스트에는 게임 상태·난수·localStorage 주입을 사용하지 않았다. 저장은 읽어서 행동을 고르고, 실제 새로고침 전후 동일한 저장이 유지되는지 비교했다.

## 저장 호환

고전16방, 이전20방, V9.9의 네 구역 저장을 **별도 격리 컨텍스트의 명시적 저장 fixture**로 확인했다. 이것은 일반 플레이 검증과 구분한다. 기존 위치·주머니·턴은 그대로 로드되며 기믹을 덧붙이지 않는다. 새 탐험 확인 취소는 원래 저장을 유지하고, 시작을 눌렀을 때만 새 기믹 원정을 만든다. 신규 저장의 새로고침과 최고 기록 보존도 통과했다. [원자료](V10-legacy-results.json).

## 화면과 공개 배포의 구분

선택한 실제 스크린샷은 [V10 화면 폴더](../visual/implemented/v10/)에 보관했다. 지도2종, 경로 비용, 수정 정지, 수문, 제단과 실제 결산을 포함한다. 휴대폰 뷰포트의 로컬 Chromium 조작이며 실물 기기 인증이나 사람 초심자 평가가 아니다.
