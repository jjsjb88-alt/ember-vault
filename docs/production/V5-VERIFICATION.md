# V5 실행 검수

검수: 2026-10-28 (한국시간). 승인 목업을 기반으로 수정한 실제 정적 게임을 Sites 미리보기의 Chrome에서 확인했습니다.

## 자동 검사

- 모든 런타임 JavaScript 구문 검사.
- 23개 테스트 통과. 기존 엔진 180회 시드 탐험, 저장 복원, 소음·추적·전투·영입·탈출 규칙 포함.
- 미공개 최종 자원을 바꾸어도 마지막 봉인 안내는 공개된 자원으로만 계산되는 회귀 검사.
- 32개 걷기·24개 공격 프레임의 실제 PNG 경계와 투명도 형식 확인.
- 통로 왕복 시 캐릭터 방향이 반대가 되는지, 공격 프레임에 이웃 조각이 섞이지 않는지 확인.

## 브라우저 검수

| 화면 | 결과 |
| --- | --- |
| 740×320 | 페이지 크기 일치, 토큰 페이지 버튼 최소 높이 수정 후 의도하지 않은 패널 넘침 없음 |
| 844×390 | 페이지 크기 일치, 풀 뽑기 제목·설명 잘림 수정 확인 |

| 390×844 | 페이지 크기 일치, 아래쪽 조작판·소리·교역 패널 확인, 토큰 넘침 수정 |
| 1280×720 | 페이지 크기 일치, 동일 화면 구도 유지 |

HUD 초상화는 상단 띠 아래로 의도적으로 돌출되며 페이지 스크롤을 만들지 않습니다. 검수 도구의 초상화 버튼 scrollHeight 보고는 이 의도된 돌출입니다. 게임 화면과 구분되는 검수 페이지 자체의 결과 로그 스크롤은 배포 대상에 포함하지 않습니다.

실제 입력으로 입구→이끼 낀 회랑 이동, 공격 2 피해, 적 HP 3→1, 소음 4·추적 전환, 턴 종료 반격, 재추출, 남은 적 처치, 전리품 공중제비 선택과 풀 편입을 확인했습니다. 새로고침 후 방·체력·자원이 유지됩니다.

추출에서 실제 관찰한 부분 합계: 공격/이동/기술/방어 `0/1/0/0` → `0/1/0/3` → `0/2/0/3` → `2/2/0/3` → `4/2/0/3` → 마지막 봉인 `4/2/0/3` → 최종 공개 `4/3/1/3`. 마지막 봉인 화면에서 배경 최종 자원과 능력 목록이 가려지는 것을 확인했습니다.

실행 화면: [932×430](../visual/implemented/v5-mobile-932x430.jpg).

## 범위와 한계

실제 Android/iOS 장치, 터치 지연, 배터리·메모리, 장시간 60fps는 측정하지 않았습니다. 8방향 프레임과 타이밍을 연결했으나 모든 방향의 발 접지·실루엣 연속성을 상용 최종 수준으로 인증한 것은 아닙니다. 배경 한 장을 재사용하며 기사·마법사·몬스터는 V4 원화입니다. 배포 전용 폴더에는 검수용 iframe 페이지를 남기지 않았습니다.
