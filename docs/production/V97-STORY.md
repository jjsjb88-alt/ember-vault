# V9.7 · 등불이 빌려주는 기억

2026-11-07 Asia/Seoul. V9.6의 「산 능력이 다시 나올 때」가 내부 주머니 구성과 추가 추출을 설명하던 문제를, 녹스의 거래부터 실제 재등장까지 이어지는 사건으로 고쳤다.

## 세계 안에서 같은 뜻으로 쓰는 규칙

- **메달은 실물이다.** 이전 탐험가들이 맡긴 솜씨가 남은 물건이며, 다른 인물도 보고 만진다. 주인공에게만 보이는 환영이나 주인공만의 자격이 아니다.
- **깜부기는 기억을 깨우는 등불의 불씨다.** 그 불빛 안에서는 누구나 문양의 움직임을 볼 수 있고, 등불을 든 이는 기억의 솜씨를 잠시 빌린다. 도입부에서 단검을 고쳐 쥐는 손의 변화로 먼저 경험한다.
- **식는 것은 빌린 힘이다.** 메달과 그 안의 기억은 남는다. 식은 메달은 주머니 아래칸에 모아 두었다가 다시 불빛을 받는다. “메달이 재가 되었다가 다시 나타난다”는 모순을 없앴다.
- **녹스가 건네는 것도 같은 기억이다.** 거래에서는 주인공이 문양을 짚고 깜부기가 익숙한 불빛을 새긴다. 새 메달이 차가운 이유와 바로 힘이 늘지 않는 이유가 장면 속 행동으로 이어진다. 실제로 나오는 시점은 기존 주머니 순환 규칙을 따른다.

## 장면의 연결

| 순간 | 인물이 겪는 일 | 화면과 규칙의 연결 |
|---|---|---|
| 도입 | 등불 밑 주머니의 메달 문양이 움직이고 도적의 손이 단검을 고쳐 쥔다 | 기억의 출처·공유되는 실물·힘을 빌리는 이유를 첫 추출 전에 소개 |
| 녹스와 만남 | 녹스가 깜부기와 메달의 불빛을 알아본다 | 상인이 주인공과 같은 메달을 보고 다룬다는 관계를 확인 |
| 불씨 화살 거래 | 마지막 사람이 다리를 건널 때까지 버틴 사수의 메달을 받는다 | 활 자체가 아닌 끝까지 겨눈 손의 솜씨를 빌리므로 단검에도 불씨가 이어짐. 기술3 지불, 현재 공격2 유지 |
| 아직 식어 있는 화살 | 주인공이 차가운 메달을 넣고 깜부기의 다음 불빛을 기다린다 | 내부 시드·작은 주머니·추가 추출 보장 설명을 안내에서 제거. 조작은 「다음 턴」으로 명확히 유지 |
| 실제 재등장 | 메달 공개에 맞춰 「녹스가 맡긴 사수의 기억」이 드러난다 | 실제 공개된 불씨 화살에만 서사 문구를 붙임. 이름·공격 효과·합산 숫자는 유지 |
| 손끝에 남은 기억 | 도적이 끊어진 다리 저편을 겨눈 기억과 단검의 열기를 느낀다 | 실제 추출이 끝난 뒤 자동 대화. 공격5로 수호자에게 향함 |

재등장 연출은 표시용 `memory` 옵션만 받는다. 미공개 메달이 나올 것이라고 먼저 말하지 않으며, 빠른 결과 보기와 모션 감소에서는 실제 공개 결과에 해당 메달이 있을 때만 같은 사연과 불씨 화살의 원화를 표시한다. 라이브 안내에도 사연을 포함한다. 다음 추출에서는 표시용 옵션을 다시 초기화한다. 게임 상태·RNG·거래 비용·추출 순서는 변경하지 않았다.

## 검증

런타임 24모듈 문법 검사와 기존 테스트 101개를 통과했다. 서사 테스트에서 옛 “메달이 소멸한다”는 문구를 요구하던 조건만 정리했고, 대사 길이·짧은 조작 안내·자원 수치 나열 금지·보스 스포일러 방지 검사는 유지했다.

브라우저에서는 새 컨텍스트에서 도입→유인→녹스 만남→거래→정상 저장의 새로고침·재개→실제 추출→수호자→유물→귀환→결산을 실제 터치로 진행한다. 저장이나 RNG를 주입하지 않는다. 대화의 줄별 내용과 화면 안 배치, 구매 후 공격2 유지, 실제 메달 공개 전 사연 비공개, 실제 추출 후 공격5, 원래 탐험·최고점 보존을 확인한다. 녹스를 만났다는 대화 메타데이터 갱신은 게임 자원 변화와 구분한다.

[브라우저 결과](V97-BROWSER-RESULTS.json)와 [대표 화면](../visual/implemented/v97/)에 최종 결과를 보존한다. 390×844는 일반 추출 애니메이션, 360×640·740×320은 모션 감소 경로다. 로컬 Chromium 터치 에뮬레이션이며 실제 휴대폰이나 인간 학습 평가로 표시하지 않는다.
