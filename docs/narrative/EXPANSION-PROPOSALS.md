# 잿불 금고 · 서사 확장 제안 (C)

> 구현 제안 전용 · **현재 게임에 미구현** · 규칙·저장 형식·`dist/` 변경 없음

## 문제 정의

현행 플레이는 4턴 내외의 짧은 잠입으로도 끝날 수 있다. 짧은 판 자체보다, **왜 다음 탐험을 해야 하는가**에 대한 증거와 차이가 결과 화면에 남지 않는 점이 서사적 공백이다. 금고가 소리를 기억한다는 설정과 달리, 현재 저장 `ember-vault-save-v2`에는 판을 가로지르는 기억 해금 정보가 없다. 다음 제안은 판 길이를 늘린 척하지 않고 여러 판에 걸친 목표를 만든다.

| 안 | 서사 효과 | 필요한 규칙 변경 | 저장 형식 영향 | 작업량 |
|---|---|---|---|---|
| **C1. 금고의 기억** | 매 판의 성공·실패로 봉인된 문장 하나가 드러난다. | 완주·사망·특정 유물 회수 시 기록 조각 해금. 전투/RNG 불변. | 기존 `ember-vault-save-v2` 변경 없이 별도 `ember-vault-lore-v1`에 해금 ID만 기록. | **M** |
| **C2. 유물별 증언** | 달의 눈물, 잊힌 왕관, 잿불의 심장에 각각 다른 짧은 결말. | 현행 승리 판정 유지, 결과 화면의 유물별 문장만 분기. 새 승리 조건 없음. | 기본안은 **영향 없음**. 수집 도감을 원할 때만 별도 키 추가. | **S** |
| **C3. 직업별 미완의 기록** | 도적은 가족, 기사는 부대, 마법사는 스승의 흔적을 각기 추적. | 직업별 3개 단서 조건(방 방문·유물 회수·탈출)을 탐험 결과에서 판정. 수치 변경 없음. | 별도 `ember-vault-lore-v1`에 직업별 발견 ID 기록. | **L** |

## 추천 도입 순서

1. **C2부터**: 현재 유물 3개가 이미 완전한 게임 상태로 존재하므로, 승리 화면의 짧은 문장만으로 가장 먼저 변화를 줄 수 있다. 안내는 40자 이하, 추가 화면은 만들지 않는다.
2. **C1 다음**: 단서 6개 정도를 도감처럼 수집. 첫 번째는 '누군가 들었다', 마지막은 '용은 기억 자체'에 닿게 하되, 초반에 비밀을 단정하지 않는다. 해금은 게임이 끝난 후에만 기록하고 독립 키에 저장한다.
3. **C3 마지막**: 각 직업 3회 분량의 미세한 발견으로 반복 플레이의 개인적 이유를 제공한다. 분기 인물 대사 대신, 결과 화면의 기록 문장과 유물 설명 한 줄을 활용한다.

## 제작 안전장치

- **비밀 공개 단계**: 파수병의 청취 → 메달과 제단의 의심 → 잿불의 심장/복수 탐험으로 확인. 단서 해금이 순서 밖으로 진행되어도 마지막 핵심 진실이 앞당겨 노출되지 않도록 조건을 둔다.
- **물리 규칙 존중**: 소리는 매 방 -2, 이끼 추가 -1. 경계 8 이상 턴 종료 숨결, 유물 회수 후 14턴 제한 및 낮은 경계의 주기적 숨결은 바꾸지 않는다.
- **저장 안정성**: `ember-vault-save-v2` 객체의 필드와 직렬화는 수정하지 않는다. 신규 해금은 독립 키이며 실패해도 탐험 진행을 막지 않는다. 새 저장 기능은 별도 승인 필요.
- **RNG 분리**: 단서 부여는 게임 RNG 호출을 추가하지 않고, 이미 확정된 결과(`phase`, `role`, `relic`, `visited`)만 읽는다.
- **화면 밀도**: 740×320 화면에서 결과 화면에 최대 한 줄만 추가. 새 도감은 메뉴에서 여는 별도 창으로 계획하고, 현재 UX에 중복 버튼을 늘리지 않는다.
- **분량의 착시 방지**: 이 제안은 약 4턴이라는 판 길이를 직접 늘리지 않는다. 실제 시간·방 개수·전투 시간을 늘리는 변경은 별도 밸런스 기획이 필요하다.

## 검수 기준

- C2: 세 유물 모두 각기 다른 문구가 나오되 기존 `won` 판정과 점수는 동일.
- C1: 같은 조건으로 재실행해도 해금 중복 없음. 실패·강제 종료·저장 차단 상황에서 게임 기능 정상.
- C3: 다른 직업으로 시작했을 때 기록이 섞이지 않고, 첫 판 신규 유저에게 핵심 진실이 먼저 공개되지 않음.
