# 잿불 금고 · 상업 마스터피스 계획안

기준 버전: V10.1 (`69345a6`) · 작성: 2026-11-11

## PR #20 진행 상태 — 2026-11-11

모바일 웹·약10분이라는 사용자 선택을 반영해 V11 개발 범위를6단계 전체로 확장했다. 새 원정의 생성 지도·60메달·10적·16지속 유물·직업별 풀·성장/결말·음악/효과음·PWA/저장 이전/접근성을 구현했다. [최종 변경과 측정](../production/V110-ROADMAP.md), [자동 탐험 원자료](../production/V110-campaign-results.json), [사람 테스트 양식](../production/V110-PLAYTEST-KIT.md)을 확인한다.

개발 구현과 출시 통과를 구분한다. 사람 참가자0명이며 실제10분, 첫 승리5~10판, 소리만으로 위험 구별, 영·일 잔여 번역/원어민 검수, 실기기와 최종 권리 검토는 남아 있다. 기존1단계 [V10.2 측정](../production/V102-RISK.md)과 별도 표본 결과는 보존하며 V11 숙련 정책의 높은 승률로 이를 덮지 않는다.
아래 현재 위치와 기준선 표는V10.1 당시의 기록이다. 원문 기준선 재현은 `node docs/plan/tools/baseline-v101.mjs`, 신규 비교는 `naive-bot.mjs`와 `quiet-bot.mjs`를 사용한다. 평균 턴은 완주한 판과 실패를 포함한 전체를 구분해 기록한다.

## 1. 현재 위치

상업용 마스터피스를 10으로 두면 종합 4 정도. "잘 다듬은 프로토타입(버티컬 슬라이스)"이다. 화면·안내·안정성은 인디 출시작에 가깝고, 게임의 몸통인 긴장·분량·반복 재미가 비어 있다.

| 항목 | 현재 | 목표 | 근거 |
|---|---|---|---|
| 고유 아이디어 | 7 | 9 | "금고는 발소리를 기억한다" → 메아리를 따라오는 숨결. 소리·위치·덱이 한 주제로 묶임 |
| 화면·아트 | 6 | 8 | 픽셀 배경·캐릭터·녹스·UI 톤 통일. 세로 화면은 출시작 수준 |
| 첫 5분 안내 | 6 | 8 | 바로 실제 원정으로 들어가고 안내는 선택식 |
| 기술 안정성 | 7 | 8 | 테스트 131개 통과, 콘솔 에러 0, 옛 세이브 호환 |
| 긴장·난이도 | 2 | 8 | 걷기만 하는 봇이 체력으로 죽지 않음 (2장) |
| 분량·반복 재미 | 2 | 8 | 한 판 약 10턴, 지도 1개 고정, 메달 24종, 적 3종 |
| 소리·음악 | 1 | 7 | 음악 없음, 효과음은 합성음뿐 |
| 서사 | 4 | 7 | 깜부기·녹스는 좋으나 본편에서 전개가 없음 |
| 상업 준비 | 2 | 7 | 한국어만, 웹 전용, 57MB, 설치형 아님, 장기 성장 없음 |

## 2. 기준선 측정

`node docs/plan/tools/baseline-v101.mjs` — 은밀 이동·유인·추가 교역 없이 걷기만 하고, 정비소에서는 첫 번째 능력만 영입하는 봇. 직업별 60판.

| 직업 | 승 | 평균 턴 | 이긴 판 남은 체력 | 숨결 횟수 / 맞은 횟수 |
|---|---|---|---|---|
| 도적 (체력 22) | 34/60 | 8.9 | 17.4 | 5.0 / 3.0 |
| 기사 (체력 28) | 46/60 | 10.0 | 25.8 | 5.4 / 3.7 |
| 마법사 (체력 20) | 52/60 | 9.9 | 16.3 | 4.9 / 4.5 |

- 체력으로 죽은 판 0. 진 판은 전부 귀환 시간 초과이거나 봇이 통로 조건에 막힌 경우.
- 숨결을 한 판에 3~4번 맞아도 체력이 거의 줄지 않음.
- 저장 예시: 5턴째에 심층 도착, 공격력 13으로 체력 7인 봉인병과 대면.
- 시드 40개의 지도 배치가 1가지.

결론: 핵심 규칙(조용히 걷기, 유인, 메아리 피하기)을 무시해도 이긴다. 소리를 관리할 이유가 없다.

## 3. 원칙

1. **속을 먼저, 겉은 나중.** V5~V10.1은 대부분 안내·가독성·연출이었다. 다음 단계들은 규칙과 내용이 먼저다.
2. **수치로 통과 여부를 정한다.** 각 단계에 봇 측정 기준을 둔다. 사람 테스트는 그다음.
3. **한 주제로 묶는다.** 새 요소는 "소리와 기억"에 붙을 때만 넣는다. 다른 게임의 장치를 그대로 옮기지 않는다.
4. **세이브는 깨지 않는다.** 새 규칙은 새 탐험에만 적용하고 옛 세이브는 원래 규칙으로 이어 간다(지금까지의 방식 유지).

## 4. 단계별 계획

### 1단계 — 위험을 진짜로 (규칙 수치)

목표: 소리를 무시하면 죽는다. 관리하면 산다.

- 숨결 피해 상향: `2 + ⌊메아리/3⌋` → 메아리에 더 가파르게 비례. 깊은 구역일수록 가산.
- 적 반격·체력 상향, 구역별 차등. 심층 봉인병이 공격 한 번에 쓰러지지 않게.
- 회복 축소: 보급 +6, 정비소 회복, 모닥불을 합쳐 한 판 회복량 상한을 정함.
- 경계 8 미만에서도 압박: 경계 5~7에서 적 감지 범위 증가 등 중간 단계 벌칙.
- 조용한 플레이의 보상 명확화: 은밀·숨죽이기·유인을 쓴 판이 수치로 유리해야 함.

통과 기준 (봇 60판 × 3직업):
- 걷기만 하는 봇 승률 10% 이하, 패배의 과반이 체력 0.
- 소리를 관리하는 봇(은밀 우선, 메아리 방 회피, 유인 사용)을 새로 만들어 승률 50~70%.
- 두 봇의 승률 차이 40%p 이상.
- 평균 판 길이 18~25턴.

산출물: 수치 변경, `quiet-bot.mjs`, 봇 기준을 검사하는 테스트.

### 2단계 — 매번 다른 판 (지도 생성)

목표: 두세 판 만에 동선이 외워지지 않는다.

- 구역 뼈대(상층→중층→하층→심층, 정비소 3곳)는 유지하고, 구역 안의 방 배치·연결·기믹 위치·적 배치를 시드로 생성.
- 기믹 풀 확장: 현재 검문·수정고·열쇠 지름길·압력 바닥·일방 낙하·봉인에 소리 주제 기믹 추가(울림방: 메아리 2배, 흡음방: 메아리 안 남음, 종유석: 큰 소리에 무너져 길이 막힘).
- 생성 검증기: 모든 시드에서 입구→심층→입구가 가능하고, 조용한 길과 빠른 길이 각각 하나 이상 존재.

통과 기준:
- 시드 200개에서 서로 다른 배치 150개 이상, 통과 불가능한 지도 0.
- 조용한 봇의 최적 동선이 시드마다 달라짐(같은 방 순서 반복 20% 이하).

### 3단계 — 내용 3배

목표: 덱을 "만든다"는 느낌.

- 메달 24종 → 60종 이상. 축을 세움: 은신 / 소음 활용(시끄러울수록 강함) / 메아리 조작(옮기기, 지우기, 심기) / 방어 / 추출 조작.
- 적 3종 → 10종 이상. 소리에 다르게 반응: 귀머거리(시야만), 메아리 추적자, 소리 내는 적(메아리를 대신 남김), 침묵 강요자.
- 유물(지속 효과) 15종 이상: 판마다 규칙 하나를 바꿈. 예: "유인 메아리 +3", "첫 숨결은 메아리 없는 방에서 시작".
- 직업 3종에 고유 메달 풀과 시작 유물.

통과 기준:
- 서로 다른 승리 덱 유형 5개 이상(봇 또는 사람 기록으로 확인).
- 어떤 단일 메달도 승리 덱의 80% 이상에 들어가지 않음.

### 4단계 — 판 사이 성장과 이야기

목표: 한 판이 끝나도 다음 판을 열 이유.

- 깜부기의 불씨: 원정 결과로 불씨가 자라고, 새 메달·유물·직업이 풀에 열림.
- 녹스의 거래: 판마다 대화가 이어지고, 금고가 무너진 이유와 "맨 아래 그것"의 정체가 조각으로 풀림.
- 본편 서사: 구역마다 묻힌 사람의 기억(메달의 원래 주인)을 짧은 장면으로. 튜토리얼 밖에서도 이야기가 전진.
- 상위 난이도 단계(금고가 더 오래 기억함, 숨결 범위 증가 등) 10단계.
- 결말 2개 이상.

통과 기준:
- 첫 승리까지 평균 5~10판, 모든 해금까지 30판 이상.
- 10판째에도 새 대사·새 해금이 하나 이상 나옴.

### 5단계 — 소리

목표: 주제가 소리인 게임답게.

- 음악: 구역별 4곡 + 숨결 + 정비소 + 결산. 경계 수치에 따라 층이 쌓이는 방식.
- 환경음·효과음 교체: 발소리(바닥 재질별), 메아리, 숨결 접근음. 합성음은 대체.
- 경계가 오르면 소리가 먼저 변하게 해서 화면을 안 봐도 위험을 느끼게.
- 라이선스가 분명한 음원만 사용하고 출처를 문서화.

통과 기준: 소리를 켠 테스터가 "언제 위험해졌는지"를 화면 수치 없이 맞힘.

### 6단계 — 출시 준비

- 용량: 57MB → 첫 로딩 10MB 이하(이미 있는 webp 사용, png 중복 제거, 구역별 지연 로딩).
- 설치형(PWA)·오프라인, 저장 내보내기/가져오기.
- 영어·일본어. 문자열을 코드에서 분리.
- 가로 화면 잔결함: 「능력 보기」 잘림, 방 이름표 겹침과 작은 글씨(800×360).
- 접근성: 색각 보정, 글자 크기 옵션, 진동·흔들림 끄기.
- 플랫폼: 스팀(데스크톱 래퍼)과 모바일 스토어 중 우선순위 결정.
- 권리 확인: 그림 제작 도구의 상업 이용 조건, 클랭크에서 발상을 가져온 통로 기믹의 고유화, 외부 코드 라이선스 표기.
- 사람 테스트 20명 이상, 첫 판 이탈 지점 수집.

## 5. 순서와 의존

```
1 위험 ─┬─> 2 지도 ─> 3 내용 ─> 4 성장·이야기 ─> 6 출시
        └─> 5 소리 (1단계 뒤 아무 때나 병행 가능)
```

1단계가 나머지 전부의 전제다. 위험이 없으면 지도·메달을 늘려도 고를 이유가 생기지 않는다.

## 6. 하지 않을 것

- 1단계 통과 전의 추가 안내·연출·UI 개선 (잔결함 수정 제외).
- 주제와 무관한 장치 이식.
- 멀티플레이, 실시간 요소.

## 7. 결정이 필요한 것

1. **결정됨: 모바일 한 판 약10분.** V11의 이동·적 체력·빠른 추출·귀환10턴에 반영. 실제 시간은 사람 테스트에서 확인한다.
2. **결정됨: 모바일 웹/PWA 우선.** 스팀 래퍼·모바일 스토어 등록은 이번 범위에서 진행하지 않는다.
3. 음악은 출처를 기록한 CC0, 전용 효과음은 Oculus CC BY4.0와 Wyzowl CC0를 사용. 기존 승인 아트의 변형을 재사용하며 해당 제작 도구/계정의 상업 조건은 출시 전 확인한다.
