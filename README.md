# 잿불 금고 · Ember Vault V4

한국어 싱글플레이 2D 도트 풀빌딩 던전 크롤러. 별도 설치 없이 `dist/` 정적 파일로 작동합니다.

## V4 변경

- 성인 여성 도적·기사·마법사, 초상화, 해골·수호자·용, 상자·화로·제단을 새 원화로 교체했습니다. 성당·침수된 서고·왕묘·용의 금고 4종 배경을 사용합니다. 푸른 석재와 금빛 조명으로 색감을 맞추고 초상화 비율을 유지합니다.
- 게임 화면 전체를 안전 영역을 포함한 `100dvh`에 맞춥니다. 페이지와 내부 패널 모두 스크롤하지 않습니다. 가로 화면은 왼쪽 던전과 오른쪽 조작판, 세로 화면은 던전 아래 조작판을 사용합니다.
- 이동 경로는 최대 4개의 2×2 선택판입니다. 돌멩이 유인을 켠 뒤 방을 누르면 기술 1로 소리 5를 냅니다. 숨죽이기와 풀 뽑기 버튼도 고정됩니다.
- 소리 탭은 던전 영역에 큰 지도를 표시합니다. 오른쪽에는 경계·발생/흡수 소음·적의 반응이 표시되며 적 목록은 페이지 버튼으로 넘깁니다.
- 교역은 4개 고정 칸, 이번 추출은 5개씩 순환 페이지, 전체 풀·제단은 4개씩 페이지, 일지는 3개씩 페이지, 도움말은 6개 장으로 구성했습니다. 긴 목록의 모든 항목에 접근할 수 있습니다.
- 추출의 심장 박동·봉인 해제·마지막 능력 직전 정적을 유지합니다. 추가 추출이 많아도 봉인 슬롯은 최대 5개 창으로 이동하므로 스크롤하지 않습니다. 결과는 이미 확정된 게임 상태를 표시합니다.
- 기존 저장 데이터와 V2 게임 규칙을 유지합니다. 모션 감소·효과음·빠른 추출·키보드 조작을 지원합니다.

## 플레이

턴마다 능력 5개와 추가 추출을 자동 합산합니다. 상단의 큰 공격력·이동력 숫자가 현재 잔량입니다. 기술은 영입·유인에, 방어는 피해 흡수에 사용합니다. 남은 자원은 턴 종료 때 사라집니다. 토큰을 누르면 이번 추출의 상세 목록을 볼 수 있습니다.

16개 방, 4개 깊이, 24종 능력, 3종 유물, 3개 직업이 있습니다. 유물을 회수하고 입구로 돌아오면 승리합니다. 영입한 능력은 다음 순환부터 추출하며 제단에서는 풀의 능력을 제거할 수 있습니다.

걷기·살금살금·질주와 돌·파편·물·이끼 바닥이 소리를 바꿉니다. 소리는 연결 통로를 따라 방마다 2, 이끼에서 추가 1 감소합니다. 적은 청취·조사·추적으로 반응하고 턴 끝에 마지막 소리의 방으로 한 칸 이동합니다. 수호자는 자리를 지킵니다. 숨죽이기는 이동 1로 경계 −2와 은신 +2를 얻습니다.

소리 크기의 절반을 올림한 값이 경계에 누적됩니다. 경계 8 이상이면 턴 끝에 용이 공격하고 새 턴에 경계가 2 감소합니다(도적은 추가 1). 유물 회수 후 14턴 내 귀환해야 하며 3의 배수 턴에는 용의 주기 공격이 있습니다.

- 방향키: 이동
- 1 / 2 / 3: 걷기 / 살금살금 / 질주
- A: 공격 · E: 상호작용 · C: 숨죽이기
- Space: 풀 뽑기(버튼에 포커스가 있으면 그 버튼의 기본 동작)

진행·최고 기록·설정은 브라우저 localStorage에 저장하며 기기 간 동기화하지 않습니다. 전체 화면을 지원하는 브라우저에서는 우측 상단 ⛶ 버튼을 사용할 수 있습니다.

## 검증

- `npm run check`: JavaScript 구문 검사.
- `npm test`: 엔진·추출 표시·페이지 접근성 18개 테스트. 이 중 엔진 테스트는 180회 시드 탐험을 포함합니다.
- 브라우저 뷰포트 740×320, 667×375, 844×390, 932×430, 390×667, 390×844, 1280×800에서 세 패널의 페이지 넘침·내부 넘침·화면 밖 버튼 여부를 검사했습니다.
- 740×320에서 도움말 6장, 능력 목록 6페이지, 캐릭터 선택, 제단·전리품·결과 창과 네 방향 통로를 확인했습니다. 유인과 적 반응, 전투와 보상, 8개 연쇄 추출 및 목록 페이지 전환을 확인했습니다. 실제 후퇴 이동 뒤 새로고침해 방·체력·경계·잔여 자원이 동일하게 복원되는 것도 확인했습니다.
- 검증은 브라우저 뷰포트 기준이며 실제 기기마다 브라우저 전체 화면 지원과 안전 영역은 다를 수 있습니다.

## 구현 및 아트

`engine.js`는 규칙, `art.js`는 배경·스프라이트·효과·지도 합성, `app.js`는 UI·저장·효과음, `pages.js`는 페이지 분할, `pool-reveal.js`는 추출 연출을 담당합니다. `viewport.css`가 고정 화면의 최종 배치를 정의합니다.

방 단위 탐험이며 자유 이동이나 프레임별 관절 애니메이션은 포함하지 않습니다. 단일 포즈 원화에 호흡·등장·이동·돌진·타격·파티클을 합성합니다. 원본 이미지, 최종 저장 경로와 생성 프롬프트는 [ASSETS.md](ASSETS.md)에 기록했습니다. 배포는 기존 Sites 저장소와 `.openai/hosting.json`을 사용합니다.
