# 잿불 금고 · Ember Vault

한국어 싱글플레이 2D 도트 덱빌딩 던전 크롤러. 별도 서버나 빌드 없이 `dist/`의 정적 파일로 작동합니다.

## 플레이

카드로 이동·공격·기술·방어를 얻습니다. 연결된 방을 탐험하고 적을 쓰러뜨리며 교역소에서 덱을 성장시킵니다. 유물 하나를 회수한 뒤 14턴 안에 시작 지점으로 돌아와 탈출합니다.

- 16개 방, 4개 깊이, 24종 카드, 3개 직업, 3종 유물
- 방 클릭 및 연결된 방 버튼, 카드 클릭, 공격·보상·제단·휴식·상인
- 이동하는 카메라, 전체 지도, 픽셀 캐릭터와 아이콘, 횃불, 파티클, 선택적 합성 효과음
- 소음 8 이상에서 용 공격, 유물 회수 후 주기 공격, 방어, 후퇴, 붕괴, 승리 및 패배
- 전투 보상 카드 선택, 교역소 영입과 교체, 제단의 카드 제거
- localStorage 자동 저장 및 최고 점수. 저장은 사용 중인 브라우저에 한정됩니다.
- 반응형 UI. 모바일 손패는 가로로 넘길 수 있습니다.
- 단축키: 1–5 현재 손패, 방향키 연결된 방 이동, Space 턴 종료

## 참고와 범위

사용자가 제공한 《클랭크!》, 《카타콤》 및 확장 자료의 덱 성장, 탐험, 소음, 유물 귀환이라는 핵심 구조를 참고했습니다. 원본 카드 텍스트·그림을 옮긴 공식 디지털판이 아닙니다. 룰은 싱글플레이를 위해 독립적으로 설계했으며, 그림은 코드로 만든 원본 픽셀 그래픽입니다. 원작의 모든 카드·확장·다인 규칙을 재현하지 않습니다.

카드 사용은 자원을 생성하고 공격 버튼으로 현재 방의 적에게 피해를 줍니다. 구매·보상 카드는 버린 더미에 추가되고, 뽑을 덱이 비면 버린 더미를 섞습니다. 적이 살아 있으면 진입했던 방으로만 후퇴할 수 있습니다. 유물 교체는 붕괴 시간을 초기화하지 않습니다. 위치는 방 단위로 이동합니다.

## 소스

- `dist/engine.js`: 결정적 시드 기반 상태·규칙 엔진
- `dist/art.js`: Canvas 픽셀 그래픽 및 카메라
- `dist/app.js`: 한국어 UI, 접근 가능한 버튼·모달, 효과음, 저장
- `dist/style.css`: 데스크톱·모바일 레이아웃
- `tests/engine.test.mjs`: 카드 순환, 전투, 저장, 보상, 경로, 실패·탈출 검증

## 검사

`npm run check`로 JS 구문을 확인하고 `npm test`로 규칙 및 180회 시드 경로를 검사합니다. 기본 유물 경로 90회와 심층 유물 경로 90회를 포함합니다. 심층 경로는 덱을 구매하지 않는 탐험자가 실패할 수 있도록 허용합니다.

Sites의 소스 저장소와 `.openai/hosting.json`을 사용해 배포합니다.
