# 잿불 금고 · Ember Vault V5

한국어 싱글플레이 2D 풀빌딩 던전 크롤러. `dist/`의 정적 파일로 작동하며, 능력을 뽑으면 자원이 자동 합산됩니다.

## V5.1 — 다음 방을 눌러 이동

던전 안의 금빛 방 이름을 한 번 누르면 해당 방으로 이동합니다. 연결된 방마다 방향·이동 비용·발생 소리를 표시하며, 이동할 수 없는 이유와 후퇴 경로를 구분합니다. 미니맵과 펼친 지도에서도 연결된 방을 눌러 이동하고, 펼친 지도에서는 이동 후 던전으로 돌아옵니다. 이동력이 부족하면 풀 뽑기를 안내합니다. 유인 모드에서는 같은 방 버튼으로 돌멩이를 던집니다.

## V5 — 승인 목업의 실제 화면 구현

- 푸른 석재·금빛 촛불·청록 수로로 구성된 서고 배경 위에 실제 캐릭터, 적, 상호작용 물체와 HUD를 합성합니다. 텍스트와 조작 버튼은 HTML로 작동합니다.
- 공격력·이동력을 크게 표시하고, 항상 보이는 반투명 미니맵을 우측 상단에 배치했습니다. 이동·소리·교역, 네 통로, 유인·숨죽이기, 풀 뽑기는 고정 위치에 있습니다.
- 도적의 걷기는 8방향 × 4프레임, 공격은 8방향 × 준비·타격·복귀 3프레임을 사용합니다. 방 그래프의 통로는 등각 투영 방향으로 연결됩니다. 방향별 그림을 실제로 사용하며 도적을 단순 좌우 반전하지 않습니다.
- 불규칙한 아틀라스의 프레임별 경계·발 위치를 기록했습니다. 공격 프레임 추출 시 이웃 실루엣이 섞이는 문제는 런타임 연결 성분 분리로 방지합니다.
- 검은 금빛 봉인 메달, 부분 합계, 5칸 능력 표시와 마지막 봉인 직전 1.5초 정적을 연결했습니다. 추출 도중 배경의 최종 자원·체력·골드·손패·적 정보·조작판을 숨깁니다. 상황 안내도 공개된 능력만으로 계산합니다.
- 740×320부터 휴대폰 가로 화면에서 페이지 스크롤 없이 플레이합니다. 세로 화면에는 조작판이 아래로 배치됩니다. 효과음, 빠른 추출, 모션 감소, 키보드와 기존 저장 데이터를 유지합니다.

## 플레이

능력 5개와 추가 추출은 자동으로 해결됩니다. 공격력은 전투, 이동력은 통로 이동, 기술은 능력 영입·유인, 방어는 피해 흡수에 쓰입니다. 턴 종료 시 남은 자원은 사라집니다. 토큰을 누르면 이번 추출의 상세 목록이 열립니다.

16개 방·4개 깊이·24종 능력·3종 유물·3개 직업이 있습니다. 유물을 회수한 뒤 입구로 돌아오면 승리합니다. 영입한 능력은 다음 순환부터 나오며 제단에서 능력을 제거할 수 있습니다.

걷기·은밀·질주 및 바닥 재질이 소리를 결정합니다. 소리는 실제 연결 통로를 따라 방마다 2, 이끼에서 추가 1 감소합니다. 지도는 실제 도달 범위·적의 마지막 청취 목적지를 표시합니다. 무대의 타원 파동은 발생 효과이며 이동 가능한 범위를 뜻하지 않습니다. 적은 청취·조사·추적으로 반응합니다.

- 방향키: 방 이동
- 1 / 2 / 3: 걷기 / 은밀 / 질주
- A: 공격 · E: 상호작용 · C: 숨죽이기
- Space: 풀 뽑기

진행·최고 기록·설정은 기기별 브라우저에 저장됩니다. 효과음과 추출 속도는 탐험 메뉴에서 바꿀 수 있습니다.

## 검증

`npm run check`로 모든 런타임 JavaScript를 검사하고 `npm test`로 25개 테스트를 실행합니다. 180회 시드 탐험, 추출 합계와 RNG 불변성, 최종 결과 누출 방지, 지도 방향, 프레임 이미지 경계와 공격 실루엣 분리, 연결된 방의 클릭 영역과 이동 제한을 포함합니다. 브라우저 검수 기록은 [V5 검수](docs/production/V5-VERIFICATION.md), [V5.1 이동 검수](docs/production/V51-VERIFICATION.md)에 있습니다.

## 구현 범위

이번 버전은 승인 목업을 실행 화면으로 옮긴 첫 단계입니다. 서고 배경 한 장을 방별 색조·적·물체와 함께 재사용합니다. 방마다 별도의 모듈형 공간을 제작하는 작업은 남아 있습니다. 기사·마법사·몬스터는 기존 V4 단일 포즈를 사용합니다. 도적 애니메이션도 4프레임 걷기와 3단계 공격이므로 상용 최종 모션은 추가 정리가 필요합니다. 방 단위 턴제이며 자유 이동 게임은 아닙니다.

`engine.js`: 규칙. `scene-v5.js`: 무대·캐릭터·소음·지도. `app.js`: UI·저장·효과음. `pool-reveal.js`: 추출. `vault-v5.css`: 목업 레이아웃. 승인 기준은 [아트 디렉션](docs/visual/ART-DIRECTION.md), 신규 에셋 정보는 [V5 에셋](docs/visual/ASSETS-V5.json)을 참고하세요.
