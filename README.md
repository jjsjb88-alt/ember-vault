# 잿불 금고 · Ember Vault V2

한국어 싱글플레이 2D 도트 풀빌딩 던전 크롤러. 별도 서버나 설치 없이 정적 `dist/` 파일로 작동합니다.

## 이번 버전

- 카드를 직접 내는 단계를 없앴습니다. 턴마다 능력 5개를 자동으로 추출하고 추가 추출까지 연쇄 처리합니다. 결과 토큰이 펼쳐지며 공격·이동·기술·방어가 합산됩니다.
- 공격력과 이동력은 화면 상단의 큰 숫자로 표시합니다. 숫자 옆의 총량과 현재 잔량을 구분하며, 모바일에서는 자원 표시가 상단에 고정됩니다.
- 16개 방, 4개 깊이, 24종 능력, 3종 유물, 3개 직업을 제공합니다. 영입·전리품은 다음 순환에 들어가고 제단에서 능력을 제거할 수 있습니다.
- 세 주인공은 서로 다른 미형 성인 여성 캐릭터입니다. 새 도트 스프라이트와 큰 선택 화면 초상화를 적용했습니다. 던전 배경, 적 스프라이트, 조명, 먼지, 발자국, 타격·피격 효과, 소리의 파장을 별도로 합성합니다.
- 이동 방식은 걷기·살금살금·질주입니다. 바닥 재질(돌, 파편, 물, 이끼)이 실제 소리를 바꿉니다.
- 소리는 연결된 통로를 따라 전파되고 방마다 2, 이끼 방에서 추가로 1 감소합니다. 소리를 들은 적은 청취·조사·추적으로 반응하고 마지막으로 들은 위치로 턴당 한 방씩 이동합니다. 유물 수호자는 자리를 지킵니다.
- 기술 1로 인접 방에 돌멩이 소리 5를 내어 유인할 수 있습니다. 이동 1로 숨죽이면 경계 2를 줄이고 다음 개인 소리를 흡수하는 은신 2를 얻습니다. 각각 턴당 한 번입니다.
- 소리 크기의 절반(올림)이 던전 경계에 누적됩니다. 경계 8 이상이면 턴 종료에 용이 공격합니다. 새 턴 경계 감소는 기본 2, 도적 3입니다.
- 유물 회수 후 14턴 내 귀환, 용의 주기 공격, 방어, 후퇴, 전투 보상, 휴식, 상인, 붕괴와 점수를 구현했습니다.
- 기존 V1 진행은 보존하고 남은 미사용 손패만 자동 합산합니다. V1 저장 원본은 지우지 않으며, V2는 별도 키로 저장합니다. 최고 기록도 이어집니다.

## 조작

지도나 통로 버튼으로 이동합니다. 공격·상호작용 버튼은 던전 바로 아래에 표시됩니다. 추출된 토큰을 따로 누를 필요가 없습니다.

- 방향키: 연결된 방으로 이동
- 1 / 2 / 3: 걷기 / 살금살금 / 질주
- A: 공격, E: 방의 상호작용, C: 숨죽이기
- Space: 다음 턴(버튼에 포커스가 있으면 해당 버튼의 기본 키보드 동작)

설정, 진행과 최고 기록은 사용 중인 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지는 않습니다. 효과음은 메뉴에서 켤 수 있으며 모션 감소 설정을 존중합니다.

## 구현 범위

방 단위의 전술 탐험입니다. 자유 이동이나 프레임별 전신 관절 애니메이션은 포함하지 않습니다. 등장·호흡·이동·돌진·타격·파티클을 새 스프라이트에 합성합니다. 여러 방은 공통 던전 원화에 재질, 조명, 오브젝트, 적을 바꾸어 사용합니다.

제공된 보드게임 자료의 탐험, 덱 성장, 소음과 유물 귀환 구조에서 출발해 독립적인 싱글플레이 규칙으로 재설계했습니다. 공식 디지털판이나 특정 상용 게임의 복제가 아닙니다. 원본 카드 그림과 문구를 가져오지 않았습니다. 생성 원화와 프롬프트는 `ASSETS.md`에 기록했습니다.

## 검사

- `npm run check`: JS 구문 검사
- `npm test`: 자동 추출, 추가 추출의 종료 보장, 능력 순환, 재질·보행, 소리 감쇠, 적의 이동·유인·기억 소멸, 은신, 전투, 보상, 용의 공격, 탈출, V1 저장 이관을 다루는 14개 테스트. 이 중 1개는 180회 시드 탐험을 검사합니다.
- 브라우저: 영입, 유인 후 적 이동, 전투, 보상, 유물 회수, 휴식, 우회 귀환, 은신 이동, 탈출까지 직접 플레이했습니다. 마법사로 3턴, 체력 20, 84점 탈출을 확인했습니다.
- 390 × 844 모바일 뷰: 페이지 가로 넘침 없음, 토큰 목록의 의도적인 가로 스크롤, 직업 선택, 이동, 상자와 저장 복원을 확인했습니다.

## 소스

`dist/engine.js`는 시드 기반 규칙 엔진, `dist/art.js`는 도트 아트 합성, `dist/app.js`는 UI·저장·효과음, `dist/style.css`는 반응형 화면입니다. 배포는 기존 Sites 소스 저장소와 `.openai/hosting.json`을 사용합니다.
